# Pains index format

`clients/PAINS-INDEX.md`. One row per pain, shared across every client who has it.

```markdown
# Pains index

| Pain | Clients | Idea |
|---|---|---|
| members book classes by phone | [fitwerk](fitwerk/INTAKE.md), [yoga-loft](yoga-loft/INTAKE.md) | — |
| invoices retyped from email into accounting | [a](a/INTAKE.md), [b](b/INTAKE.md), [c](c/INTAKE.md) | [invoice-inbox](../ideas/invoice-inbox/SIGNALS.md) |
```

## Normalizing

The same pain must land on the same row, whoever reported it.

- Name the **struggling moment**: who does what, the hard way. Under ten words.
- Role and action only. Add the industry when the pain exists only there.
- Before adding a row, read every existing row. Same struggling moment, same row, whatever the wording.

## Counting

Count distinct clients on a row. **3 clients** makes the pain a product candidate: create the idea and link it in the Idea column.
