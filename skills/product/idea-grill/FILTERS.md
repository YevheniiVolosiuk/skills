# Filters

Four pass/fail checks an idea clears before anyone spends time grilling it. Two minutes, not a conversation.

Mark each **pass**, **fail** or **unknown**. A fail needs a fact. With no evidence either way, it is unknown.

1. **Money.** At least one level-4 signal on the [signal ladder](../client-intake/SIGNALS-FORMAT.md#signal-ladder): someone already paid, posted a paid job, or named a budget for this pain.
2. **Reachable.** The people with the pain can be reached in writing, in English or Polish: forums, job boards, email, review sites.
3. **Small.** One web developer can ship a first version people would pay for in about 4 weeks.
4. **Open.** No well-loved tool already owns it. Complaints about the existing tools count as a pass.

## Outcome

- **Any fail** → REJECT, with the failed filter as the killer.
- **Unknowns** → grill anyway; each unknown becomes a load-bearing assumption.
- **All pass** → grill.
